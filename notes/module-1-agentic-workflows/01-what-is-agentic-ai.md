# 01. 에이전틱 AI란 무엇인가 (What is agentic AI?)

> Module 1 · Lesson 1
> 다음 → [02. 자율성의 정도](02-degrees-of-autonomy.md)

## 한 줄 요약

에이전틱 워크플로우는 **LLM 기반 앱이 하나의 작업을 완료하기 위해 여러 단계를 실행하는 프로세스**다.
시간은 더 걸리지만 결과물의 품질이 크게 올라간다.

---

## 1. 기존 LLM 사용 방식 vs. 에이전틱 워크플로우

| | 기존(non-agentic) 방식 | 에이전틱 워크플로우 |
|---|---|---|
| 진행 방식 | 처음부터 끝까지 한 번의 선형적 흐름 | 반복적(iterative) 사이클 |
| 비유 | 사람에게 **백스페이스 없이** 에세이를 한 번에 써달라고 요청 | 초안 쓰고 → 고치고 → 다시 고치는 실제 글쓰기 |
| 소요 시간 | 짧음 | 김 |
| 결과 품질 | 표면적 | 훨씬 나음 |

에이전틱 워크플로우의 전형적인 사이클:

```
아웃라인 작성 → 웹 리서치 필요 여부 판단 → 리서치 수행
    → 초안 작성 → 검토·수정할 부분 파악 → 수정 → (반복)
```

## 2. 에이전틱 AI 워크플로우의 정의

**LLM 기반 앱이 하나의 작업을 완료하기 위해 여러 단계를 실행하는 프로세스.**

예시 체인:

1. 하나의 LLM이 아웃라인 작성
2. 다른 LLM이 검색어 결정
3. 검색 결과가 에세이 초안을 작성하는 LLM에 입력됨
4. 또 다른 LLM이 수정이 필요한 부분을 검토(reflect)
5. *(선택)* 핵심 사실을 검증하는 **사람 개입(human-in-the-loop)** 단계
6. 최종 수정

> 각 단계를 서로 다른 LLM 호출이 맡는다는 점이 핵심이다.
> "똑똑한 모델 하나"가 아니라 "역할이 나뉜 여러 번의 호출"로 품질을 만든다.

## 3. 이 강좌의 핵심 스킬 — 작업 분해

복잡한 작업을 **더 작은 단계들로 분해**하고, 각 단계를 잘 수행할 컴포넌트를 구축하는 것.

이 분해(decomposition) 스킬이 이 강좌의 중심이며,
다양한 애플리케이션에서 에이전틱 워크플로우를 구축하는 능력을 좌우한다.

→ 자세한 방법론은 [05. 작업 분해](05-task-decomposition.md)에서 다룬다.

## 4. 실습 예제 — 리서치 에이전트

강좌 전체를 관통하는 예제. 예시 주제는 **"스페이스X와 경쟁할 새로운 로켓 회사를 어떻게 만들까?"**

```
리서치 계획 수립
  → 웹 검색 엔진 호출 및 페이지 다운로드
  → 결과 종합·순위화
  → 아웃라인 작성
  → "편집자" 에이전트가 일관성 검토
  → 종합 마크다운 리포트 생성 (서론, 배경, 결과 등)
```

여러 출처에서 정보를 가져와 더 깊이 사고하므로,
모델에게 직접 에세이를 써달라고 하는 것보다 훨씬 정교한 리포트가 나온다.

강사는 **법률 준수(legal compliance), 헬스케어, 비즈니스/제품 리서치** 등의 분야에서
이와 유사한 전문 리서치 에이전트를 직접 구축한 경험이 있다고 언급.

## 5. 다음 레슨 예고

에이전틱 워크플로우가 **얼마나 자율적일 수 있는지**.
매우 자율적인 복잡한 워크플로우부터 단순하지만 유용한 것까지 다양하며,
애플리케이션별 구축 난이도를 판단하는 프레임워크도 함께 다룬다.
